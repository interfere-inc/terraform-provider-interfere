# interfere_network_rules (Resource)

Manage the complete list of networks allowed to reach a workspace's dashboard and API. Each apply replaces every rule in the workspace, including rules added in the dashboard. Destroying the resource saves an empty list, which removes all network restrictions. The network the apply runs from must match a rule, or the API rejects the change; if the runner's egress later leaves the list, Terraform loses access to the workspace until an administrator on an allowed network fixes the rules. Import using the workspace slug.

~> **Destroying this resource removes every network restriction.** Destroy saves an empty rules list, so the workspace dashboard and API become reachable from any network. Removing the resource from configuration has the same effect; use a `removed` block with `destroy = false` to stop managing the rules without clearing them.

~> **Keep the Terraform runner's egress in the list.** The API rejects a save that would block the network the request comes from, so the runner's egress IP address, range or ASN must match a rule. If that egress changes after an apply, the provider can no longer read or update the rules until an administrator on an allowed network adds the new egress in the dashboard.

Each apply replaces the complete list, including rules added in the dashboard. Non-empty lists require the Enterprise plan; an empty list is always allowed. The provider credential needs `org:workspace_auth:read` and `org:workspace_auth:write`.

## Example Usage

```terraform
resource "interfere_network_rules" "workspace" {
  workspace_slug = "example"

  rules = [
    {
      label = "Office"
      value = "203.0.113.0/24"
    },
    {
      label = "Terraform runner egress"
      value = "198.51.100.7/32"
    },
    {
      label = "Corporate VPN"
      value = "2001:db8:1200::/40"
    },
    {
      label = "Zero Trust egress"
      value = "AS13335"
    },
  ]
}
```
