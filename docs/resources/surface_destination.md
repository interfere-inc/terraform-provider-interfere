# interfere_surface_destination (Resource)

~> **Deprecated in provider 0.x; removed in 1.0.** This page documents retained legacy compatibility. New SDK services use a workspace secret and stable service name; this resource is not a setup prerequisite. Preserve retained data when stopping Terraform management: use a `removed` block with `lifecycle { destroy = false }` on the compatible provider version and review the plan before upgrading.

Manage a surface's destination mapping through an existing integration. Import with workspace-slug/surface-slug. Destroy unlinks the mapping without deleting the surface or integration.

## Example Usage

```terraform
resource "interfere_surface_destination" "web" {
  workspace_slug = "example"
  surface_slug   = "web"
  integration_id = "installation-id"
  project_id     = "prj_example"
}
```
