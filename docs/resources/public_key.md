# interfere_public_key (Resource)

~> **Deprecated legacy setup.** Public keys are retained for compatibility with existing clients. New SDK 13.0.x services use a workspace secret and a build-generated release token; do not create a public key for keyless setup.

SDK 13.0.x setup uses a workspace secret and a stable service name. Supply the secret as `INTERFERE_API_KEY` to the build with `release:write`, and to the server with `org:telemetry:write` for server telemetry. The framework plugin registers the release, bakes its release token into the browser bundle, and handles source maps automatically. Keep the secret out of browser code.

Configure `serviceName` in `withInterfere()` or `interfere()`; it defaults to the unscoped package name. Terraform does not need to create an App or a public key for this setup.

Manage a surface's publishable key. Configuration changes replace the key. Creation UUIDs are generated automatically unless explicitly configured. Import using workspace-slug/surface-slug/key-uuid. External rotation refreshes content; destruction revokes the key and its rotation grace-period values.

## Example Usage

```terraform
resource "interfere_public_key" "browser" {
  workspace_slug = "example"
  surface_slug   = "web"
  name           = "Browser"
}
```
